# 📝 Age Calculator

A simple web application that calculates a person's age based on their date of birth and displays the result in years, months, and days.

---

## 📌 Features  
✅ Easy-to-use interface  
✅ Accurate age calculation (years, months, and days)  
✅ Fully responsive design  
✅ Built with **HTML, CSS, and JavaScript**  

---

## 🚀 Live Demo  
🔗 **[Try it here](https://omniayehiia.github.io/Age-Calculator/)**  

---

## 🛠️ Technologies Used  
- **HTML** - for structuring the web page  
- **CSS** - for styling and layout  
- **JavaScript** - for age calculation logic

## 🔧 How to Use  
1️⃣ Enter your **date of birth** in the input field.  
2️⃣ Click the **"Calculate Age"** button.  
3️⃣ Your exact age in years, months, and days will be displayed below.
